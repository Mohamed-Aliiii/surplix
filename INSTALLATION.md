# SURPLIX — Complete Version 2 (contact updated)

This is a complete replacement project, not a patch. It includes the storefront, product detail view, cart, styling, Vite configuration, and GitHub Pages workflow.

## Install on Mac
1. Stop the existing Vite server with Ctrl+C.
2. Back up `~/Desktop/surplix-starter` before making changes.
3. Extract this ZIP, then move the `surplix` folder to your Desktop.
4. In Terminal run:

```bash
cd ~/Desktop/surplix
npm install
npm run dev
```

5. Open the local address shown by Vite, usually http://localhost:5173/.
